PyTorch is not installed for the Python running this app, so conversion cannot start. In the same environment as python3 app.py, run python3 -m pip install torch torchvision (use a CUDA wheel from pytorch.org if you have an NVIDIA GPU), then restart the app.

FFmpeg is required to write the depth MP4. On a Mac run brew install ffmpeg then restart the app with python3 app.py --replace. If Homebrew already installed it, the app looks in /opt/homebrew/bin.

Running on CPU. The first 32-frame window often takes 30–90 seconds with little bar movement — that is the model working, not a hang. A GPU makes this much faster.

Advanced

Long videos stream in overlapping 32-frame windows, so length is not limited by RAM. The Small model is Apache-2.0. Base and Large checkpoints are CC-BY-NC-4.0.
